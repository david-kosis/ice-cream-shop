# 🍦 Frosty Scoop

A modern, responsive ice-cream storefront built with **HTML, CSS and JavaScript**.

## Features

- Product flavor cards
- Search and category filters
- Add-to-cart functionality
- Quantity controls and automatic totals
- Persistent cart using localStorage
- Dark/light mode
- Responsive mobile navigation
- Demo checkout flow
- Newsletter signup interaction

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Customize

Edit the `products` array in `script.js` to change flavors, prices, descriptions and emojis.

## Tech

HTML5 · CSS3 · Vanilla JavaScript
